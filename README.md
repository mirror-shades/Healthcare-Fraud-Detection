# Healthcare Fraud Detection Model

This is a machine learning model trained to detect healthcare fraud. It is written in as a Python notebook using Pandas, SciKit-Learn, and Matplotlib. Further analysis is provided regarding tuning, analysis, and heuristics.


## To run
It is recommended to use a venv to download the requirements used to run this notebook.
```
pip install -r requirements.txt
jupyter lab healthcare_fraud_detection.ipynb
```
